# IRun

Windows 桌面虚拟跑步与定位模拟工具，支持路线选择、速度与配速设置、记圈、距离提醒及运动轨迹可视化。

各版本的功能新增与修复见[更新日志](CHANGELOG.md)。

## 系统支持

Windows 安装包支持 Intel/AMD x64 的 Windows 10（1809 及以上）和 Windows 11。

| 手机系统 | 连接方式 | 要求 |
| --- | --- | --- |
| iOS / iPadOS 17.0–17.3.x | RemoteXPC / QUIC 隧道 | 开启开发者模式，以管理员身份运行 IRun，安装 Apple 网络设备驱动并启用 IPv6 |
| iOS 17.4–26.x | USB 用户态隧道 | 开启开发者模式，通常无需管理员权限 |
| iOS 27.x | USB 用户态隧道 | 开启开发者模式，使用 Cryptex 开发者镜像；iOS 27.3.1 Beta 已有用户实测 |

最低支持 iOS / iPadOS 17。早期 iOS 17 所需的 Apple 网络设备驱动可能需要手动配置。

## 安装与使用

运行 Windows x64 安装包并同意 Windows 的管理员授权。安装包已包含 Python、Qt、iOS 连接程序和位置模拟所需的运行库。安装器会复用已有的 Apple 移动设备服务和 USB 驱动，并联网下载、验证签名、安装缺失的组件。若 Windows 要求重启，重启后再连接手机。

IRun 优先使用随包附带的 Personalized 或 Cryptex 开发者镜像。预置镜像无法使用时，程序会尝试复用已下载的镜像，必要时从 GitHub 下载。首次准备镜像仍可能需要连接苹果签名服务。Windows 端无需另行安装 Python、Qt 或运行命令。

1. 通过 USB 连接并解锁设备，确认“信任此电脑”，再到“设置 → 隐私与安全性”开启开发者模式。
2. 选择路线，再选择编辑运动速度（m/s）或运动配速（分:秒 / 公里）。修改后另一项自动更新。
3. 按需启用距离提醒，从下拉菜单滚动选择 1–20 公里，或输入自定义公里数，例如 2.5。
4. 点击「开始」。暂停时保留当前模拟位置，运动时间、进度和距离停止累计。点击「继续」从同一点恢复，或点击「停止并恢复定位」结束。

速度按实际经过时间推进，并计入设备通信耗时；手机应用测得的速度仍受坐标采样和应用算法影响。通信长时间无响应时会停止模拟并尝试恢复定位。

跑步设置在运行中也能修改，有效改动会立即应用并显示提示。达到目标距离后提醒一次并继续运行。Windows 通知可能受系统设置或请勿打扰模式影响。界面支持跟随系统、浅色和深色主题。

升级前先停止运动并关闭软件，再运行新安装包。IRun 会读取原 VRun 用户路线并迁移设置。卸载 IRun 不会卸载 Apple 驱动。

## 路线与统计

首次打开时，使用「绘制路线」或「导入路线」添加自己的路线。

点击「导入路线」并选择 GPX 1.1 文件。文件含多个连续路段时，可在预览中选择一段。首尾分开的路线默认按往返保存。勾选「保存为闭合环线」后，预览用虚线标出连接起点和终点的补线。GPX 使用 WGS-84，用户路线默认保存在 `%LOCALAPPDATA%\IRun\routes`。

点击「绘制路线」打开地图。选中路线时，起始视图定位到该路线的起点。输入「纬度, 经度」后可定位或直接添加路线点。滚轮缩放，拖动空白处平移，点击添加路线点，拖动点修正，或用「撤销」回退。

绘图地图左上角的「+」「−」可缩放，左下角的比例尺会随缩放和地图位置更新。

正式版使用在线 OpenStreetMap，不预置地点或离线底图。空白路线从全局视野开始，编辑已有路线时，初始视野会适应该路线。地图加载失败时可使用能访问 OpenStreetMap 的网络代理，仍可通过坐标画路线。路线按 WGS-84 保存和导出。

主页面的路线预览使用相同的底图源，按路线范围缩放，并在底图上显示轨迹和运动进度。

绘制时可以直接保存为往返路线。点击绿色起点或「闭合路线」可切换为闭合环线。通过「管理路线」可搜索和筛选路线、预览、重新编辑、复制、重命名、删除及导出 GPX。编辑时可右键在线段上插入点、从地图上删除点，也可撤销或重做。导出的往返路线保留单程坐标，再次导入后仍可用于往返。

仍可将兼容的 UTF-8 TXT 文件放入安装目录的 `routes` 文件夹，重启后即可选择。旧 TXT 使用包含 `lat`、`lng` 的 BD-09 坐标，应用会自动转换为 WGS-84 并闭合路线。

闭合路线每回到起点记一圈。非闭合路线到达终点后沿原路线折返，回到起点记一次往返。「已运动距离（估算）」随模拟位置累计，包含去程及返程。图中显示模拟位置和当前进度，其他应用可能按各自的算法统计距离。

## 故障排查

- 设置中没有「开发者模式」：先解锁设备并完成 USB 信任。配对通过后，IRun 会尝试显示开关。如果仍未出现，可连接运行 Xcode 的 Mac 发起配对，再在手机的「设置 → 隐私与安全性」开启，重启后解锁并确认。出现 `SavePairRecord 183` 时，应先在 Windows 的「Apple 设备」或 iTunes 确认设备能被正常识别和信任。

- 无法连接：检查 USB、手机解锁与信任状态和开发者模式。Apple USB 组件状态由 IRun 自动检查，结果可在诊断报告中查看。
- 恢复定位失败：连接同一台手机，再次点击“停止并恢复定位”。正常关闭窗口也会尝试恢复；断电、拔线或强制结束程序时无法保证恢复。
- 反馈报错：点击主界面底部的「导出诊断日志」，保存文本并检查内容后发送给维护者。其中包括当前报错和近期连接日志，程序会尝试隐藏常见的设备标识、坐标和密钥。
- 设置保存在当前用户的 Software\IRun\IRun 注册表项；iOS 17+ 镜像和配对缓存由 pymobiledevice3 管理。

## 开发与构建

源码运行、自动化测试和 Windows x64 打包统一使用 64 位 Python 3.12。安装包已包含 Python 运行环境，使用安装版无需单独安装 Python。

双击项目根目录的 [Run-IRun.bat](Run-IRun.bat) 可启动源码版。脚本会创建或复用项目内的 `.venv-irun`，并按 `requirements.txt` 补齐依赖。已安装 uv 时，脚本可以通过 uv 准备 Python。首次安装依赖通常需要联网。

如需手动运行测试或构建，请先在终端选用 64 位 Python 3.12。构建安装包还需要 Inno Setup 6/7。

    python -m pip install -r requirements-dev.txt
    python scripts/prepare_ddi.py
    python main.py
    python -m pytest -q
    python scripts/build.py --installer

应用输出到 dist/IRun，安装包输出到 release。可通过 INNO_ISCC 指定 Inno Setup 编译器。requirements-ios17.txt 固定独立定位组件的依赖版本。

发布构建须先提交源码，随包附带的源码 ZIP 由当前提交生成。默认构建为公开版。若需内部定制，须同时传入 `--offline-map-pack`（仓库外的 ZIP 文件，包含 `views.json` 和 `tiles/z/x/y.png`）与 `--edition`（构建标签）。定制应用及安装包分别输出到 `dist/editions/<标签>` 和 `release/editions/<标签>`，地图包只进入定制应用和安装包。

生成安装包前，构建脚本会对照上游的两套 iOS 镜像，核对构建号和全部文件的 SHA-256。上游内容变化时，先运行 `python scripts/prepare_ddi.py --update` 更新 `ios17_helper/ddi-lock.json` 和本地镜像，然后用对应设备验证两种安装方式，再构建发布包。镜像文件由构建脚本获取，Git 中记录来源提交和校验值。
